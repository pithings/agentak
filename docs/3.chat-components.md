# Chat components

`ChatPanel` is the main framework component. It renders the full chat and receives a
required `session` prop.

Create the session once. Dispose of it when your app no longer needs the conversation.

## React

```tsx
import { useEffect, useMemo } from "react";
import { ChatPanel } from "agentak/react";
import { createPiSession } from "agentak/pi";

export function Assistant() {
  const session = useMemo(() => createPiSession(), []);

  useEffect(() => () => session.dispose(), [session]);

  return <ChatPanel session={session} style={{ height: "600px" }} />;
}
```

## Vue

```vue
<script setup lang="ts">
import { onBeforeUnmount } from "vue";
import { ChatPanel } from "agentak/vue";
import { createPiSession } from "agentak/pi";

const session = createPiSession();
onBeforeUnmount(() => session.dispose());
</script>

<template>
  <ChatPanel :session="session" class="h-[600px]" />
</template>
```

## Preact

```tsx
import { render } from "preact";
import { ChatPanel } from "agentak/preact";
import { createPiSession } from "agentak/pi";

const session = createPiSession();

render(
  <ChatPanel session={session} style={{ height: "600px" }} />,
  document.querySelector("#app")!,
);
```

Call `session.dispose()` when you unmount the app or switch to another conversation.

## Plain JavaScript

Use `mountChat()` when your page does not use a framework:

```ts
import { mountChat } from "agentak";
import { createPiSession } from "agentak/pi";

const session = createPiSession();
const chat = mountChat("#chat", { session });

// Apply new props without losing the conversation.
chat.update({ session, generateTitle: true });

// Clean up when finished.
chat.unmount();
session.dispose();
```

`mountChat(target, props)` accepts a CSS selector or an element. It adds Agentak's CSS
variables, prepares the target as a container, and renders the chat.

It returns two methods:

- `update(props)` applies new props without resetting the transcript.
- `unmount()` clears the target element.

Neither method disposes of the session.

## `ChatPanel` props

The React, Vue, and Preact components accept the same main props:

| Prop                  | Type            | Description                                                           |
| --------------------- | --------------- | --------------------------------------------------------------------- |
| `session`             | `ChatSession`   | Runs the conversation. Required.                                      |
| `generateTitle`       | `boolean`       | Asks the model to create a title. This uses one extra request.        |
| `tokens`              | `boolean`       | Set to `false` if your page already provides Agentak's CSS variables. |
| `actions`             | Preact children | Adds content to the end of the header.                                |
| `emptyActions`        | Preact children | Adds content below the greeting before the first message.             |
| `class` / `className` | `string`        | Adds a class to the wrapper element.                                  |
| `style`               | style object    | Styles the wrapper element. Use it to set the height.                 |

Use `class` with Vue and `className` with React or Preact. Vue also accepts `style`.

The chat UI uses Preact in every framework. In React and Vue, `actions` and `emptyActions`
must therefore be Preact children. Create them with `h()` from `preact`, or leave them
out.

## Use `AgentChat` without a wrapper

Import `AgentChat` from `agentak` when a Preact layout already provides the container:

```tsx
import { h } from "preact";
import { AgentChat, injectTokens } from "agentak";
import { createPiSession } from "agentak/pi";

injectTokens();
const session = createPiSession();

<AgentChat
  session={session}
  style={{ height: "600px" }}
  actions={h("button", null, "Minimise")}
  emptyActions={h("p", null, "Ask me about this page.")}
/>;
```

`AgentChat` accepts `session`, `generateTitle`, `actions`, `emptyActions`, `className`, and
`style`. It does not inject theme variables. Call `injectTokens()` yourself, or provide
the variables in your own CSS.

## Control the chat with `ChatView`

Use `ChatView` when your app owns the transcript and callbacks. It renders the low-level
`Chat` component inside the same framework wrapper, but it does not need a session.

```tsx
import { ChatView } from "agentak/react";

<ChatView
  messages={messages}
  isStreaming={streaming}
  onSend={send}
  onStop={stop}
  onReset={clear}
  style={{ height: "600px" }}
/>;
```

`ChatView` accepts every `Chat` prop. It also accepts `tokens`, `class` / `className`, and
`style` for the wrapper element.

In Vue, callbacks are props rather than events:

```vue
<ChatView
  :messages="messages"
  :is-streaming="streaming"
  :on-send="send"
  :on-stop="stop"
  :on-reset="clear"
  class="h-[600px]"
/>
```

## Session and conversation rules

- One session represents one conversation.
- Changing the provider, model, key, or thinking level does not reset the conversation.
- To switch conversations, create or restore another session and pass it to the component.
- Changing `generateTitle` does not create a new session.
- The component never calls `dispose()` on a session.

See [Save conversations](./5.conversations.md) to keep a transcript between visits.
