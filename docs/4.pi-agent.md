# Pi agent

`agentak/pi` provides Agentak's included agent. It combines
[pi-agent-core](https://www.npmjs.com/package/@earendil-works/pi-agent-core), a provider
picker, and any tools that you add.

This is the only Agentak import that loads an agent loop. If you use your own session, you
do not need it.

## Create a session

```ts
import { createPiSession } from "agentak/pi";

const session = createPiSession();

// Mount the chat with this session.
// Later, when the conversation is no longer needed:
session.dispose();
```

With no options, the first message opens the provider picker if no usable provider and
model are already saved. Free providers need no API key.

You can also set the provider and instructions in code:

```ts
const session = createPiSession({
  provider: "openai",
  apiKey: "sk-…",
  systemPrompt: "You are a support agent for example.com. Keep answers short.",
  approvals: "never",
});
```

Create the session once, outside your render function.

## Options

| Option          | Type                                                      | Description                                                        |
| --------------- | --------------------------------------------------------- | ------------------------------------------------------------------ |
| `provider`      | `string`                                                  | Provider to open. Uses the saved provider by default.              |
| `snapshot`      | `PiSnapshot`                                              | Saved conversation to open.                                        |
| `apiKey`        | `string \| Record<string, string>`                        | One key, or one key for each provider. Free providers need no key. |
| `generateTitle` | `boolean`                                                 | Lets the model name the conversation. This uses one extra request. |
| `thinkingLevel` | `off \| minimal \| low \| medium \| high \| xhigh \| max` | Starting thinking level. Defaults to `off`.                        |
| `systemPrompt`  | `string`                                                  | Agent instructions. Defaults to a short assistant prompt.          |
| `tools`         | `AgentTool[]`                                             | Tools available to the agent. Empty by default.                    |
| `approvals`     | `"always" \| "once" \| "never"`                           | When to confirm tool calls. Defaults to once for each tool.        |
| `streamFn`      | `StreamFn`                                                | Custom streaming function. Mainly useful in tests.                 |

`createPiSession()` returns a `PiSession`. It implements `ChatSession` and adds two methods:

- `save()` returns a snapshot that you can store.
- `dispose()` stops listeners and releases the session.

See [Save conversations](./5.conversations.md) for `save()` and `snapshot` examples.

## Providers

| Provider                           | API key  | API                  |
| ---------------------------------- | -------- | -------------------- |
| LLM7, Kilo, OVHcloud, OpenCode Zen | Free     | OpenAI Completions   |
| Vercel AI Gateway, OpenRouter      | Required | Depends on the model |
| OpenAI                             | Required | OpenAI Responses     |
| Groq, Cerebras                     | Required | OpenAI Completions   |

Agentak stores one key for each provider. A key entered in the picker stays in
`localStorage` and is sent directly to that provider.

Regular web pages show 7 providers. Kilo and OpenCode Zen do not support CORS preflight
requests, so they are only available in the Chrome extension. The extension shows all 9
providers.

Provider code and model lists load only when they are needed. A provider's model list
loads after the user chooses it. Its API code loads on the first request.

## Add tools

Agentak includes no tools. Without tools, the agent answers from the conversation alone.

A tool is a Pi `AgentTool` with a name, label, description, TypeBox schema, and `execute()`
function:

```ts
import { Type } from "typebox";
import { createPiSession } from "agentak/pi";

const session = createPiSession({
  tools: [
    {
      name: "read_page",
      label: "Read the page",
      description: "Read the visible text of the current page.",
      parameters: Type.Object({}, { additionalProperties: false }),
      execute: () =>
        Promise.resolve({
          content: [{ type: "text", text: document.body.innerText }],
          details: undefined,
        }),
    },
  ],
});
```

The chat asks the user before it runs a tool. Change this with `approvals`:

- `"always"` asks for every call.
- `"once"` asks once for each tool. This is the default.
- `"never"` runs tools without asking.

Only use `"never"` for tools that are safe to run without confirmation.

## Lower-level APIs

`createPiSession()` provides the complete setup. For more control, use the lower-level
exports:

```ts
import { createAgent, createAgentStore, useAgent } from "agentak/pi";
```

- `createAgent()` returns the Pi agent and its approval handler.
- `createAgentStore()` converts agent events into chat state.
- `useAgent()` provides the same state as a Preact hook.

Most apps only need `createPiSession()`.
