# Getting started

Agentak adds a complete AI chat to a web page. It provides the chat interface, provider
settings, and a session API. You can use its Pi agent or connect your own agent.

## Install

```sh
npx nypm i agentak
```

Agentak has separate imports for the chat UI and the included agent. Your app only loads
the Pi agent when it imports `agentak/pi`.

## Add a chat

This example works in a page without a framework:

```html
<div id="chat" style="height: 600px"></div>

<script type="module">
  import { mountChat } from "https://esm.sh/agentak";
  import { createPiSession } from "https://esm.sh/agentak/pi";

  const session = createPiSession();
  const chat = mountChat("#chat", { session });

  // Call these when your page no longer needs the chat:
  // chat.unmount();
  // session.dispose();
</script>
```

The chat fills its container, so give the container a height.

When the user sends their first message, Agentak opens the provider picker if no usable
provider and model are already saved. The user can choose a free provider without entering
an API key. Agentak remembers the provider, model, thinking level, and any key entered in
the picker.

Each framework package exports two components:

- `ChatPanel` runs from a `ChatSession`.
- `ChatView` lets your app provide the transcript and callbacks directly.

## Use the included agent

Create one session for each conversation:

```ts
import { createPiSession } from "agentak/pi";

const session = createPiSession({
  provider: "openai",
  apiKey: "sk-…",
  systemPrompt: "You are a support agent. Keep answers short.",
});
```

Call `session.dispose()` when you no longer need the conversation. The UI does not dispose
of sessions because it did not create them.

Read [Pi agent](./4.pi-agent.md) for provider, model, tool, and session options.

## Bring your own agent

The UI only needs a `ChatSession`. If you do not import `agentak/pi`, the Pi agent is not
included in your bundle.

Read [Custom agents](./6.custom-agents.md) to implement a session for another agent or
backend.

## Browser storage and API keys

Keys entered in the provider picker are stored in `localStorage`. The browser sends a key
directly to the selected provider. Agentak does not need your own server.

Do not place a private server key in public client code. Pass a key in code only when it is
safe for every visitor to use it. For private credentials, connect Agentak to your own
backend with a custom session.

Regular web pages show 7 providers. Kilo and OpenCode Zen do not accept browser CORS
preflight requests, so they are only available in the Chrome extension. The extension
shows all 9 providers.
