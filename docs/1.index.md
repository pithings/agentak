# Agentak

Agentak is a complete AI chat UI for React, Vue, Preact, and plain JavaScript. Use the
included Pi agent or connect the UI to your own agent.

- Stream answers and render Markdown and code blocks.
- Let users choose a provider, model, thinking level, and API key.
- Add tool calls, approvals, queued messages, and conversation restore.
- Use inline styles with light and dark themes.
- Choose from 9 providers, including free options that need no API key.

## Try it

The button in the corner of this page opens the chat itself. Send a message. If no
provider is selected, the picker opens so you can choose a free provider and start.
